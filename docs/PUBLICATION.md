# 공개본 안내

2026-11-21 기존 로컬 개발 산출물을 면접용으로 정리한 공개 스냅샷이다.

실제 AWS 계정·리소스 ID, OpenStack UUID, 내부 접속 주소와 서비스 도메인은 예시 값으로 일관되게 치환했다. 인증 정보, 개인키, Terraform 상태, 배포 응답 원문, 개인정보가 포함된 문서와 스크린샷은 포함하지 않았다. 예시 값은 실제 환경에서 사용할 수 없다.

`source-manifest.json`은 원본 산출물과 공개 경로의 대응을 기록한다. 공개 정리용 README·검증 보고서는 이번 정리 과정에서 추가했다. 코드의 기존 파일 생성일을 Git 커밋 날짜로 소급하지 않는다.

팀 프로젝트에서 담당 부분을 중심으로 공개한 코드다. 팀이 만든 기존 환경·연동 코드를 개인이 모두 독립 개발한 것으로 주장하지 않는다. AI 도구를 활용해 개발·정리했으며, 검증 범위와 실행 결과는 별도 기록한다. 원본 운영 환경에 즉시 배포하는 패키지가 아니며 환경별 설정과 팀 공통 의존성이 필요하다.
